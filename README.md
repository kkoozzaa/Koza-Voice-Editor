# Koza Voice Editor 🎙️

## 📚 About the Project

Koza Voice Editor is a Python application that allows you to boost your microphone volume in real time.

It was created to make microphone audio louder and easier to hear while using applications such as Discord, games or voice chat programs.

## 🚀 Features

- Boost microphone volume in real time.
- Select your microphone as the audio input.
- Send the processed audio to other applications.
- Simple and easy-to-use interface.

## ⚙️ Requirements

- Python
- VB-CABLE Virtual Audio Device
- A working microphone

## 💻 How to Use

1. Download and install [VB-CABLE](https://vb-audio.com/Cable/).
2. Start Koza Voice Editor.
3. Select your microphone as the input device.
4. Select **CABLE Input (VB-Audio)** as the output device.
5. Select **CABLE Output (VB-Audio)** as your microphone in Discord or another application.
6. Adjust your microphone volume.

## 🛠️ Technologies

- Python
- VB-CABLE

## 🎯 Goal

The goal of this project is to provide a simple way to increase microphone volume in real time without needing complicated audio software.
